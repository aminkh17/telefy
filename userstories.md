# A client app for telegram but only shows music files, not text not other media's nothing, except music files.

# Core Access & Filtering

- As a user, I want to log in with my Telegram account so that I can access my existing chats.
- As a user, I want the app to automatically filter and display only audio/music files so that I don’t see irrelevant text, images, or videos.

- As a user, I want to browse a list of all music files shared in my chats so that I can quickly find songs without scrolling through other content.

# Playback & Controls
- As a user, I want to play music files directly in the app so that I don’t need to open external players.

- As a user, I want basic playback controls (play, pause, skip, seek) so that I can manage listening easily.

- As a user, I want to see track metadata (file name, duration, sender) so that I know what I’m listening to.

# Organization & Discovery
- As a user, I want to search for music files by name or sender so that I can quickly locate specific tracks.

# Notifications & Updates
- As a user, I want to receive notifications when new music files are shared so that I don’t miss fresh tracks.

- As a user, I want to mark favorite tracks as liked so that I can easily return to them later.
